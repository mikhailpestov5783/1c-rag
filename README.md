# RAG чатбот

## Описание
RAG-система, разработанная полностью на платформе 1С:Предприятие 8.3.
Для работы необходимы развернутая LLM-модель (на данный момент поддерживается Ollama API) и векторная база данных ChromaDB.

## Установка
1. Открыть конфигуратор
2. Выполнить команду `Конфигурация -> Загрузить конфигурацию из файлов`. Выбрать пункт `XML` и папку с проектом.
